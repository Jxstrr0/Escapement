# src/: the source of index.html

**Edit `src/`, run `node build.js`, commit `src/`, `index.html` and `sw.js` together. Never hand-edit `index.html` or `sw.js`.**

`index.html` is the shipped artifact: one self-contained page, served by GitHub Pages from `main` and saved for offline use. `build.js` (repo root, node, no dependencies, copied from PEW) concatenates the files listed in `src/manifest.txt`, in that order, byte for byte. It adds no wrappers and does no reformatting.

```
node build.js            # write index.html and sw.js from src/
node build.js --check    # exit 1 if index.html or sw.js != what src/ builds; names the first differing src file and line
```

(`--absorb` and `--split` came along with PEW's build.js; Escapement never had a single-file era, so they aren't needed.)

## How the files fit together

- The files are **slices of one page**. A `.js` file may open or close in the middle of an IIFE, so `node --check` on a single file is meaningless. Test the built `index.html`.
- The first file of each `<script>` block starts with its `<script>` line and the last file of the block ends with `</script>`: `sim/parts.js` … `sim/market.js`, `sound/tick.js` on its own, `vis/core.js` … `vis/api.js`, and `app/state.js` … `app/help.js`.
- Every file except the last ends with a newline (`build.js` refuses otherwise). `html/tail.html` holds the page's last line, with no trailing newline. Empty files are refused: a stub needs at least its header comment.
- A new file must be added to `manifest.txt` at the right position; `build.js` refuses to build if a file in `src/` is missing from it, and refuses leftover merge-conflict markers.
- Scope is shared within each script block. `WATCH_SIM` is one IIFE over the sim files, `WATCH_VIS` one IIFE over the vis files, and the app is one top-level script over the app files. `start()` runs after the whole app block has loaded (`__ldGo` in `app/boot.js`), so later app files can add to tables and `TAB_RENDER` freely.

## PWA files (repo root, not in src/)

`manifest.webmanifest` and `icons/` are committed by hand (icons from `node tools/make-icons.js`, needs Playwright). **`sw.js` is generated by `node build.js`**: its cache name is `esc-shell-v<VERSION>-<hash of index.html + manifest + icons>`, so every release changes it and installed copies show the update bar. The worker also precaches every CDN `<script src>` in the page plus the `ESC_LIBS` array in `html/body.html`. All cache names start `esc-`, and the worker only deletes `esc-` caches: other Kelbo games share this origin. After a merge conflict in `sw.js` or `index.html`: `git checkout --theirs index.html sw.js && node build.js`.

## VERSION

One place: `src/app/state.js`, `const VERSION="x.y.z.w";`.
