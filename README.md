# Escapement

A watchmaking career game by Longlight Interactive. Build mechanical movements part by part, put them on the timegrapher, chase chronometer certification, and grow a shared repair bench in the Haldis into a manufacture making its own calibres. Free, phone-first, plays in the browser and installs as an app.

**Play:** https://escapement.longlight.games/

Work in progress: see [`docs/ESCAPEMENT-PLAN.md`](docs/ESCAPEMENT-PLAN.md) for the build plan and [`docs/DESIGN.md`](docs/DESIGN.md) for what is built so far. Developer notes are in [`CLAUDE.md`](CLAUDE.md).
